# Security policy

## Supported versions

Security fixes are applied to the latest TF Switcher release available from the
Visual Studio Marketplace. Update to the latest version before reporting a
problem that may already have been corrected.

## Reporting a vulnerability

Do not publish exploit details, credentials, access tokens, private Terraform
configuration, or other sensitive information in a public issue.

To request a private reporting channel, open a minimal
[security contact request](https://github.com/345dave/tfswitcher-docs/issues/new?template=security_contact.yml)
containing only:

- A statement that you may have found a security vulnerability.
- A safe way for the maintainer to contact you.
- The affected TF Switcher version and operating system.

Do not include reproduction steps or technical vulnerability details in that
public request. The maintainer will arrange a private follow-up.

For ordinary defects that do not expose sensitive information, use the
[bug report form](https://github.com/345dave/tfswitcher-docs/issues/new?template=bug_report.yml).
